# ARC Motor — сайт arcmotor.ru

## О проекте
Одностраничный сайт по продаже электромотоциклов из Китая. Деплой: GitHub Pages, домен arcmotor.ru. Главный файл — index.html (весь HTML/CSS/JS в одном файле). Блог в папке blog/. Фото в images/.

## Ключевые правила ценообразования
- Курс пересчёта: 1 RMB = 26.1 ₽. Эта цена УЖЕ включает комиссию и доставку до Москвы.
- На карточке модели цена "От" = минимальная конфигурация (самый слабый мотор + самая маленькая батарея).
- В модальном окне цена пересчитывается при выборе мотора/батареи.
- Можно задавать цену напрямую в рублях через поле priceRub вместо rmb.

## Правила по контенту
- Категория прав: всегда "Категория М" — управление с правами B. НЕ указывать мощность в кВт рядом с категорией (по документам все моторы ≤3.8 кВт). Формулировка мягкая, без чисел.
- Тип привода называется "мотор-колесо" (НЕ "втулочный").
- Аккумулятор НЕ съёмный — не писать что его можно снять и унести.
- Характеристики на карточках = максимальные значения для модели.

## Структура моделей (JS объект MODELS в index.html)
Каждая модель: name, tag, desc, base (характеристики), motors (по типам wheel/chain/belt/mid), batteries, defaultMotor, defaultBattery. Константа RATE=26.1. Хелпер priceOf() использует priceRub если задан, иначе rmb*RATE.

## Галерея
Доп. фото моделей: images/moto-{код}-2.webp, -3.webp и т.д. (до 12, поддерживает пропуски в нумерации). Сайт находит их сам.
